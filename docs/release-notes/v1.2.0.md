# OpenPhantasie 1.2.0

**No game files are included.** As before, OpenPhantasie builds each game from your own copy on first start. Installed
copies update themselves (Options → General → UPDATE NOW, or the check at start).

## Downloads

- Windows: `OpenPhantasie-1.2.0-win-x64.zip`: unzip and run `OpenPhantasie.exe`
- Linux: `OpenPhantasie-1.2.0-linux-x64.tar.gz`: unpack and run `OpenPhantasie/OpenPhantasie`
- macOS: `OpenPhantasie-1.2.0-osx-arm64.tar.gz` (Apple silicon) or `-osx-x64.tar.gz` (Intel): unpack and open
  `OpenPhantasie.app` (not notarised: right-click → Open the first time)

## New

- **Apple II Phantasie III** imports on its own (v3.0, and the cracked v1.0), with its own art. Where the Apple's
  numbers differ from DOS's, DOS's are used. Lines the Apple prints in its own words now show in the Apple's wording.
- **Apple II Phantasie II v2.1** imports, like v1.0.
- **Commodore 64 Phantasie I** (C64PP v1.4, `.d64` or `.g64`) imports its game data, with the C64's text and DOS's
  numbers. There is no C64 picture pack yet: with only the C64 copy the game plays without pictures. Import a DOS or
  Amiga copy as well to get its art.

## Fixed / changed

- Dialog panels are opaque and no longer cut through the Guild's header.
- Status lines name the town ("Entered Pelnor.") instead of "town #8".
- The Guild hint names E to exit, as the bar and the manual do.
- The combat line writes monster names as the originals do: "Combat vs 1 Scribe(s), 5 Scribe(s)!".
- Phantasie III: two-line save / load / distribute / purge questions show in full on the status line; Encounter
  answers stay on screen a moment; the orders list names the spell; town letter keys move the highlight.
