# OpenPhantasie 1.1.0

**No game files are included.** As before, OpenPhantasie builds each game from your own copy on first start. Installed
copies update themselves (Options → General → UPDATE NOW, or the check at start).

## Downloads

- Windows: `OpenPhantasie-1.1.0-win-x64.zip`: unzip and run `OpenPhantasie.exe`
- Linux: `OpenPhantasie-1.1.0-linux-x64.tar.gz`: unpack and run `OpenPhantasie/OpenPhantasie`
- macOS: `OpenPhantasie-1.1.0-osx-arm64.tar.gz` (Apple silicon) or `-osx-x64.tar.gz` (Intel): unpack and open
  `OpenPhantasie.app` (not notarised: right-click → Open the first time)

## New

- **Reset the game** (I–IV): put a save back to a new game's world, keeping or erasing the characters.
- **Amiga-only imports:** Phantasie I and Phantasie III now import from the Amiga disk alone, with no DOS copy needed.
  Where the Amiga's numbers differ from DOS's, DOS's are used.
- **Played copies:** a played DOS Phantasie I copy, or a played Apple II Phantasie II copy, can have its maps put back
  to the start (fog of war) during import.
- **Phantasie III:** a Fireflash option. The default follows the manual; the other choice uses DOS's roll, which scales
  with the caster's INT.
- **Importer:** reads SSI's 16-sector Apple II disks (RDOS 3.3), so Phantasie II v2.1 and the Apple II Phantasie III
  disks (including the original v3.0) are now named correctly ("recognised", not "another build"). These versions
  can't be imported yet.

## Fixed / changed

- Phantasie I and II hand out the fight's XP and gold when you enter a town, as the manual (p. 15) and the originals
  do, not only through Distribute.
- Phantasie III: the hand-out's usable rows, the Armory checks gold before the pack, trap and lava damage as in DOS,
  the welcome line, the inspect screen's bow row and the Guild list layout.
- Phantasie IV: event payments larger than the purse take what it holds, under the 65,000 cap; gold amounts in events
  wrap as on the X68000.
- Guild treasury: Transportation between towns starts a new treasury trip.
- Esc in Reset the game steps back to the save picker.
- Fixes to Phantasie II scrolls, the treasury and the Phantasie IV translation, and two Amiga Phantasie I name typos.
