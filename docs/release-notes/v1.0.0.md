# OpenPhantasie 1.0.0

The first release: SSI's Phantasie I, II and III and the Japanese-only Phantasie IV (in English) in one game, with the
originals' rules as the default and quality-of-life changes as options.

**No game files are included.** On first start, OpenPhantasie asks for your own copy of each game (disk images, a zip,
an installed folder, or your Steam / GOG "Phantasie Memorial Set") and builds the game's data, text, art and sound from
it. The README lists the supported versions.

## Downloads

- Windows: `OpenPhantasie-1.0.0-win-x64.zip`: unzip and run `OpenPhantasie.exe`
- Linux: `OpenPhantasie-1.0.0-linux-x64.tar.gz`: unpack and run `OpenPhantasie/OpenPhantasie`
- macOS: `OpenPhantasie-1.0.0-osx-arm64.tar.gz` (Apple silicon) or `-osx-x64.tar.gz` (Intel): unpack and open
  `OpenPhantasie.app` (not notarised: right-click → Open the first time)

## What's in it

- Phantasie I (DOS rules, Amiga or DOS CGA pictures), Phantasie II (Atari ST rules and pictures, or Apple II pictures),
  Phantasie III (DOS rules, Amiga or DOS CGA pictures), Phantasie IV (X68000, translated into English)
- Each game's original title pictures and music, sound effects through models of the original machines' audio
- Party transfer between the games, as the originals allow, plus optional transfers they don't
- Options per game, locked into each save: original (manual), DOS, or remaster presets, and individual switches
- Mouse and gamepad support, an inventory screen, auto-map, colourblind palette and more, each switchable
- Updates itself: a check at start (Options → General → CHECK UPDATES AT START) and UPDATE NOW
